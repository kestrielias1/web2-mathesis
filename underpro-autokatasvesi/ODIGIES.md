# Σελίδα «Αυτόματη Κατάσβεση» για το underpro-security.gr (Divi 5)

## Αρχεία

| Αρχείο | Τι είναι |
|---|---|
| `autokatasvesi-divi.json` | Το layout της σελίδας για εισαγωγή στο Divi. Περιέχει και τις 9 φωτογραφίες. |
| `images/` | Οι ίδιες φωτογραφίες ξεχωριστά, για χειροκίνητο ανέβασμα αν χρειαστεί. |
| `build_divi.py` | Το script που φτιάχνει το JSON. Αλλάζετε κείμενα εδώ και το ξανατρέχετε με `python3 build_divi.py`. |

Το JSON είναι σε μορφή Divi 4 (context `et_builder`). Το Divi 5 τη μετατρέπει αυτόματα σε μορφή Divi 5 κατά την εισαγωγή.

## Εισαγωγή (περίπου 5 λεπτά)

1. **Πρώτα κάντε backup** ή δοκιμάστε σε staging.
2. WordPress → **Σελίδες → Προσθήκη νέας**. Τίτλος π.χ. «Αυτόματη Κατάσβεση». Αποθηκεύστε ως πρόχειρο.
3. Ανοίξτε τη σελίδα με το **Divi Builder** και διαλέξτε «Build from scratch».
4. Πατήστε το εικονίδιο **Portability** (τα δύο βελάκια, πάνω αριστερά στις ρυθμίσεις σελίδας) → καρτέλα **Import**.
5. Διαλέξτε το `autokatasvesi-divi.json`. Αφήστε το «Replace existing content» τσεκαρισμένο και πατήστε **Import**.
6. Περιμένετε όσο το Divi ανεβάζει τις φωτογραφίες στη Βιβλιοθήκη Πολυμέσων.
7. **Save** και άνοιγμα της σελίδας για έλεγχο σε desktop και κινητό.
8. Ρυθμίσεις σελίδας: Page Layout → **No Sidebar / Fullwidth**, όπως στις άλλες σελίδες σας.

## Αν κάτι δεν βγει σωστά

- **Οι φωτογραφίες δεν εμφανίζονται:** ανεβάστε τα αρχεία του φακέλου `images/` στα Πολυμέσα και επιλέξτε τα σε κάθε Image module (τα ονόματα ταιριάζουν, π.χ. `feidias-hero.jpg` είναι η φωτογραφία της εισαγωγής).
- **Χάθηκε η εμφάνιση (χρώματα, κάρτες):** όλο το styling είναι σε ένα **Code module** στην πρώτη ενότητα (admin label «Α. Εισαγωγή», κρυφή πρώτη γραμμή). Αν το αφαιρέσετε, χάνεται το design. Αν προτιμάτε, μεταφέρετε το περιεχόμενό του στο Divi → Theme Options → Custom CSS (χωρίς τα `<style>` tags).
- **Μήνυμα «This file should not be imported in this context»:** κάνατε import από τη Divi Library. Κάντε το από τον Builder της σελίδας (βήμα 4).

## Δομή σελίδας

| Ενότητα | Admin label στο Divi | Τι περιέχει |
|---|---|---|
| Α | Α. Εισαγωγή | Τίτλος, κουμπιά ραντεβού/τηλεφώνου, φωτογραφία ΦΕΙΔΙΑΣ, styling |
| Β | Β. Γιατί κάθε λεπτό μετράει | Χρονολόγιο πυρκαγιάς, διεθνή και ελληνικά στατιστικά |
| Γ | Γ. ΦΕΙΔΙΑΣ (σωλήνας) | Περιγραφή, λειτουργία, λευκή και μαύρη σειρά |
| Δ | Δ. AMFE (φιαλίδια) | Περιγραφή, θερμοκρασίες, κεφαλές, μεγέθη |
| Ε | Ε. Σύγκριση | Πίνακας σωλήνας ή φιαλίδιο |
| ΣΤ | ΣΤ. Το αέριο FK-5-1-12 | Ιδιότητες κατασβεστικού |
| Ζ | Ζ. Εφαρμογές | Πού τοποθετούνται |
| Η | Η. Επικοινωνία | Κλείστε ραντεβού, τηλέφωνο, email, διεύθυνση |
| Θ | Θ. Πηγές | Πηγές όλων των στατιστικών |

Τα απλά κείμενα είναι σε **Text modules** και αλλάζουν κανονικά από το Divi. Το χρονολόγιο, οι κάρτες στατιστικών, ο πίνακας σύγκρισης και τα πλακίδια είναι σε **Code modules** (HTML).

## Πριν βγει live

- Οι φωτογραφίες είναι κομμένες από τα φυλλάδια της MOBIAK. Ζητήστε από τη MOBIAK τα πρωτότυπα σε υψηλή ανάλυση και την άδεια χρήσης τους.
- Τα ελληνικά στατιστικά είναι μέσοι όροι 2010–2019 του Αρχηγείου Π.Σ. Νεότερα στοιχεία (2024–2025) υπάρχουν στα [ανοιχτά δεδομένα του Πυροσβεστικού Σώματος](https://www.fireservice.gr/synola-dedomenon).
